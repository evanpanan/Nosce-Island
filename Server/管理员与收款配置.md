# 0.6.0 管理员与苹果内购

管理员登录配置使用 ADMIN_USERNAME + ADMIN_PASSWORD（14 字符以上）。ADMIN_TOTP_SECRET 可选。高级用户可设置 ADMIN_PASSWORD_HASH 替代明文环境变量，此时它优先于 ADMIN_PASSWORD。会话使用服务端持久记录与 HttpOnly/Secure/SameSite Cookie，注销和密码变更使旧会话失效。不存在公开默认账号密码。

App 用户保持匿名，使用 StoreKit 验证 AppTransaction，服务器以 Apple 官方库再次验签后，将购买身份与匿名用户 UUID 关联。购买使用 appAccountToken 并核对 App Store 身份。订单签名验证通过并入账之后客户端才 finish；暂停新售卖不妨碍恢复已购权益。所有后台记录由服务端产生，客户端不能提交“已付费”状态。

当前收费权益与价格尚未确定，默认 COMMERCE_SALES_ENABLED=false。发布前必须真正实现收费权益、配置 App Store Connect 商品，完成 Sandbox 购买、续费、恢复、退款和真机验证。不能把测试替身或 Pro 标签当成商用付款验收。

Vercel、密钥变量、通知地址和 Xcode 配置步骤请读根目录 Vercel部署与Xcode联调.md。私钥仅放服务器私密变量，不放 App、仓库或聊天。
